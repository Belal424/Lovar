# تحديث LOVAR: صفحات المنتجات والـ Checkout واللغتين

- `product.html?id=PRODUCT_ID`: صفحة مستقلة لكل منتج.
- `checkout.html`: صفحة مستقلة لإتمام الشراء.
- `storefront-i18n.js`: ترجمة واجهة المتجر وحفظ اللغة المختارة في المتصفح.
- سلة المشتريات تُحفظ في `localStorage` لتنتقل بين الصفحات.

## التثبيت
استبدل ملفات مجلد `github-pages` على استضافتك بالملفات الموجودة في هذا المجلد، مع الاحتفاظ بـ `api-config.js` الذي يحتوي رابط Apps Script الحالي. لا يلزم تعديل أو إعادة نشر Apps Script لهذا التحديث.

## ملاحظة بخصوص المحتوى العربي
عناصر الواجهة مترجمة. أسماء المنتجات وأوصافها تظهر باللغة التي أُدخلت بها في Google Sheets. صفحة المنتج تدعم حقلي `nameAr` و`descriptionAr` إن تمت إضافتهما لاحقًا إلى بيانات المنتج، لكنها تستخدم الاسم والوصف الأساسيين كبديل.
